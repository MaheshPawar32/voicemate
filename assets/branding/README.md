# VoiceMate branding assets

Extract `VoiceMate_Play_Store_Artwork_Pack.zip` into the repository root to add:
- `voicemate_icon_512.png` – Google Play and Flutter launcher icon source.
- `voicemate_feature_graphic_1024x500.png` – Google Play feature graphic.

The `pubspec.yaml` launcher-icon configuration and `bootstrap_android.sh` expect the icon file at this path. After extracting the artwork pack, run the bootstrap script once to generate Android launcher resources.
