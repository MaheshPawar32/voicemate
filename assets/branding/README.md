# Vokey branding

| File | Use |
|---|---|
| `vokey_icon_source.png` | Original 1254×1254 artwork (no text) supplied by the product owner. |
| `vokey_icon_1024.png` | Launcher-icon master (black corner bleed trimmed), RGBA. Input to `flutter_launcher_icons`; also shown on the in-app splash. |
| `vokey_play_store_icon_512.png` | **Google Play hi-res icon**: 512×512, 32-bit PNG (RGBA), ~330 KB (< 1 MB limit). Upload in Play Console → Store presence → Main store listing. Play applies its own corner mask. |
| `reference/vokey_ui_reference.png` | UI direction board for the redesign (design mockups, **not** app screenshots — never upload these as store screenshots). |

Regenerate launcher icons after changing the master: `dart run flutter_launcher_icons`.
